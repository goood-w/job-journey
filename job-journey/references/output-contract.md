# 输出协议

## 固定顺序

1. 重大风险提醒：仅在存在重大风险时出现，必须置顶。
2. 当前任务：说明识别到的阶段、主任务和自动补齐的必要前置工作。
3. 主体结果：直接完成用户请求，不先讲方法论。
4. 评分：只展示当前材料支持的固定维度。
5. 证据与限制：区分事实、公开信息、推断、冲突和待确认。
6. 待补材料：只列会改变当前判断的内容。
7. 下一步：不超过五项，按优先级排序。

## 单项评分格式

```text
岗位职责、层级与价值：75/100
可信度：中
判断：岗位价值较好，但决策权限和团队规模尚待确认。
```

待确定时：

```text
个人与岗位匹配：待确定
原因：尚未提供足以支持判断的个人经历材料。
补齐后可做：逐项要求映射、个人匹配评分和综合总分。
```

## 重大风险格式

```text
重大风险：存在
类型：高风险推断
信号：岗位同时承担销售承诺、产品规划和交付结果，但JD未体现资源调度权。
影响：可能出现权责不匹配和绩效目标不可控。
核实问题：谁对售前承诺、资源排期和最终交付负责？
```

## 长度控制

- 用户只问一个问题时，输出聚焦该问题。
- “完整分析”才展开当前材料支持的全部相关模块。
- 不重复粘贴大段 JD、简历或逐字稿。
- 不默认创建页面、Dashboard或多页报告。
