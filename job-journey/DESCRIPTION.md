# job-journey Skill 描述

## GitHub About（推荐）

隐私优先、以事实和来源为基础的八阶段求职全流程 Skill，覆盖求职定位、岗位发现、公司与 JD 分析、人岗逐项映射、简历投递、面试准备与复盘、Offer 比较和入职规划。

## 一句话介绍

把从“开始找岗位”到“完成入职”的求职过程，整理成八个可独立调用、可持续衔接的 AI 工作阶段。

## 完整描述

`job-journey` 面向正在跳槽、转岗、求职或谈薪的个人用户。它能够读取用户授权的岗位 JD、简历、岗位表格、截图、网页链接、项目资料、面试记录和 Offer 文件，自动识别当前主任务，并调用对应的八阶段方法完成岗位分析、个人资料结构化、人岗逐项映射、简历定制、面试准备与复盘、Offer 比较及入职计划。

Skill 坚持事实与推断分离：资料不足时继续完成不依赖该材料的部分，无法确认的内容保持待确定，不用猜测填满结论。所有岗位评价采用统一六维百分制；只有六维都有有效得分时才显示综合总分。个人数据默认最小读取、最小保存，运行时资料与 Skill 安装目录隔离。

## English description

A privacy-first, evidence-grounded eight-stage job search skill covering career positioning, job discovery, JD and company analysis, person-role mapping, resume tailoring, interview preparation and review, offer comparison, negotiation, and onboarding planning.
