# 八阶段验证与迭代记录

日期：2026-09-18

八个阶段均完成一次无 Skill 基线与启用 Skill 的对照测试。最终版本共检查 44 项规则，选定输出通过 44/44。

## 分阶段结果

| 阶段 | 最终结果 | 是否迭代 | 主要验证点 |
|---|---:|---:|---|
| 1 求职定位 | 6/6 | 是 | 不在缺少薪酬基线时自造涨薪百分比 |
| 2 岗位发现与初筛 | 5/5 | 否 | 多格式接入、来源保留、无简历继续岗位侧分析 |
| 3 公司与岗位分析 | 5/5 | 否 | 重大风险置顶、六维口径、事实与推断分离 |
| 4 人岗逐项映射 | 6/6 | 是 | 冲突保留、指标口径、任期计算边界 |
| 5 简历与投递 | 6/6 | 是 | 不编造数据、不把普通证据缺口称为重大风险 |
| 6 面试准备 | 6/6 | 是 | 预测题边界、守真回答、一次只问一题 |
| 7 面试复盘 | 5/5 | 否 | 逐题诊断、数据核验、复试准备范围 |
| 8 Offer 与入职 | 5/5 | 否 | 同口径薪酬、六维评分、总分门槛和建议性质计划 |

## 根据真实输出补齐的规则

1. 用户只说“明显涨薪”时，不设定 20%、30% 等数字门槛；先取得薪酬基线和偏好，或只给计算方法。
2. 经历只有开始时间而没有结束时间或“仍在职”确认时，不按当前日期计算任职年限；重叠经历不得重复累计。
3. 简历数据未核实、职责边界不清或个人证据较弱，不属于岗位重大风险；使用“证据边界”“待补材料”或“个人缺口”。
4. 面试阶段同样遵守重大风险定义，不把商业化或团队管理证据不足置顶成岗位风险。

## 分析结论

通用模型已经能处理大量求职任务，因此不少基线断言也会通过。Skill 的主要增益不是生成更多内容，而是让八个阶段共享同一套材料接入、证据状态、评分、风险、隐私和范围控制协议。阶段八最能体现差异：基线未稳定使用重大风险置顶和固定六维，启用 Skill 后完整满足协议。

时间与 token 数据未在辅助评测完成通知中持久化，因此基准只报告规则通过率，不伪造性能数据。
